# 명화 디지털 갤러리 (gallery-web)

세계 유수 미술관의 명화를 1920×1080 디지털 사이니지 포맷으로 큐레이션한 온라인 갤러리.
어디서든 접속해 감상하고, 관리자는 웹에서 직접 업로드·크롭·전시 구성이 가능합니다.

## 구조

- **정적 사이트** (서버 코드 없음) — Vercel 호스팅
- **Supabase** — DB(전시/작품/음악) + Storage(이미지/음악) + Auth(관리자 로그인)
- 보안: anon key는 공개용, 쓰기 권한은 RLS 정책으로 관리자 이메일에만 부여
  - 익명: 공개된 전시/작품 읽기만 가능
  - 관리자(`gallery-admin@wellbianlabs.io`): 전시·작품·음악 CRUD, 원본 보관함 접근

## 페이지

| 경로 | 설명 |
|---|---|
| `/` | 공개 갤러리 — 전시 카드 → 소개 → 작품 그리드 → 라이트박스 / 슬라이드쇼(+음악) |
| `/admin` | 관리자 — 로그인 후 전시 생성·소개글·공개 토글·표지 지정, **브라우저 캔버스 16:9 크롭 업로드**, 작품 메타 편집·삭제·다운로드, 음악 관리 |

## 관리자 작업 흐름

1. `/admin` 로그인
2. 새 전시 만들기 (또는 기존 전시 선택)
3. **[+ 작품 업로드]** → 이미지 여러 장 선택 → 파일마다 16:9 크롭 박스 조절(파일명에서 작품명/작가/연도 자동 파싱) → 업로드
   - 브라우저에서 1920×1080 JPEG + 480px 썸네일 생성 후 Supabase Storage에 직접 업로드
   - "원본 보관" 체크 시 원본 파일도 비공개 버킷에 저장
4. 전시 공개 토글 → 즉시 공개 사이트에 반영

## 시드 (로컬 수정본 일괄 업로드)

```bash
ADMIN_PW='<관리자 비밀번호>' node seed/seed.js
```

`03.수정/` 폴더 전체를 스캔해 전시·작품을 생성합니다. 재실행해도 이미 올라간 파일은 건너뜁니다.

## 사이니지 기기 연동

안드로이드 키오스크/WebView에서 `https://<도메인>/#/play/<전시ID>` 접속 시 해당 전시 전체화면 슬라이드쇼 자동 재생.

## 로컬 개발

정적 파일이므로 아무 정적 서버로 열면 됩니다:

```bash
npx serve .
```
